# Third-party software

PySide6 / Qt: https://doc.qt.io/qtforpython-6/licenses.html
Distributed as separate dynamic libraries in the onedir package. The project uses no Qt WebEngine or Qt PDF features. Qt/PySide license files accompany the distribution. Users may replace compatible shared libraries subject to their licenses.

PyInstaller: https://pyinstaller.org/en/stable/license.html — GPL with bootloader distribution exception.

Python: https://docs.python.org/3/license.html — PSF license.

The inpoutx64 driver is not distributed or installed by this project. Hardware access protocol was cross-checked against public InpOut32 driver source (https://github.com/ellysh/InpOut32) and local N155A experiments. No external DLL is loaded by this application. Lecoo-Control-Center (https://github.com/LaVashikk/Lecoo-Control-Center) served as hardware research reference; its code and drivers are not bundled.

SQLite: https://www.sqlite.org/copyright.html — SQLite deliverable library is dedicated to the public domain. The Windows build bundles sqlite3.dll with Python's _sqlite3 extension for local monitoring history. No separate database service is installed.
