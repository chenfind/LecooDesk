# 使用说明

> **严重警告：个人实验性硬件控制软件，可能无效并可能损坏机器或电池。作者不承担由使用产生的损失或责任。重启不保证恢复。不能接受风险请退出。**

先使用演示版了解界面。正式版确认风险前不初始化硬件；可以勾选不再显示，使用说明页仍保留警告。首次默认不启用限制。

## 充电区间

拖动左右滑块设置开始/停止阈值，差值必须大于等于10%。点击“应用区间”保存；启用时同时应用到当前硬件会话。按钮宽度固定，完成后禁用并显示“区间已存”或“区间生效”。调整后再次显示“应用区间”。保存或应用失败会显示错误并允许重试。

下限用于停充后的再次充电，初次启用时并不保证电量必须先降到下限。电量估算、EC控制周期可能使显示值短暂超过上限；该功能不能保证精确的百分比硬截止。

关闭窗口只收起到系统托盘，仍在运行。点击托盘图标或再次启动可打开窗口。退出请选择“恢复原设置并退出”或左侧“恢复并退出”。正常退出尝试恢复原值；强制结束、蓝屏、断电不能保证恢复。下次启动在风险确认后尝试恢复旧会话记录，不应依赖此机制保证安全。

## 设置与日志

主题默认跟随系统。日志默认详细，可关闭或选择简单，旧用户选择会保留。日志优先放在应用目录的 `logs`，演示版为 `logs-demo`；目录不可写时回退至本地用户数据目录，设置页显示实际路径。

日志按小时或单片2MiB拆分，同小时最多21片。默认保留72小时，可设1–720小时，启动及运行期间每分钟清理；关闭期间不清理。配置及恢复记录放在 `%LOCALAPPDATA%/LecooDesk`。日志仅保存在本机，不自动上传。提交问题前请检查日志是否包含个人路径等信息。

从最终保存位置运行打包版，在设置中打开“登录 Windows 后启动”。任务记录当前程序的绝对路径和工作目录。移动或删除程序前先关闭自启，移动后从新目录重新启用。未勾选不再提示时，自启仍会等待风险确认。

在“电源数据采集”中可选择 Windows 电池接口或 EC 电量计。正常退出并重新打开后生效。EC 功率未经过外部校准，实验数据使用独立历史库，Windows 状态告警仍显示在诊断提示中。

## 运行边界

仅支持 README 所列白名单，禁止与其他修改同一EC参数的工具同时使用。不提供任意端口或寄存器写入。不刷写BIOS，不随程序安装驱动。不能据充电状态标志推断电池物理旁路供电。

报告问题时提供版本、型号、BIOS版本、操作步骤、期望/实际行为及已检查的日志。不要上传BIOS、个人数据或整个用户配置目录。

## 电源监测（0.3）

电源监测显示电量和Windows原生电池接口上报的功率，正值表示充电，负值表示放电。默认启用后台持续采集：窗口显示时每2秒，收起到托盘或最小化后每30秒。可在偏好设置选择仅窗口显示时采集，或直接关闭采集。关闭后不再发起监测查询；已经开始的单次查询可结束，但结果会丢弃。原有充电限制及必要的EC校验不受此开关影响。风险确认前不采集。

图表具有最近10分钟、1小时、6小时、24小时预设、双端时间滑块、中间拖动和平移按钮；取消跟随最新可固定历史视窗。悬停会在两图显示相同时间的游标。数据不可用显示空白或破折号，不伪装成0；历史峰值以功率范围细线保留。

本机固件可能误报充放电方向，异常样本保留系统原值并提示；采集不能证明旁路供电，也不是精密功率计。适配器功率和整机功耗没有显示，代码仅保留未来能力入口。演示版的所有监测数据均为模拟。

SQLite随软件打包，无需另装。历史库位于用户数据目录history/power.sqlite3，演示与正式版隔离，和诊断日志级别无关。最多保留24小时，最近10分钟保留原始采样，更早按30秒聚合保存有效计数、平均值及峰值。暂停、休眠和退出产生的数据缺口不补造。每分钟清理过期数据，软件关闭期间不清理。

数据库主体限定约8MiB，使用DELETE事务日志、受限事件数量和18MiB暂停阈值，以给20MiB历史目录预算留余量；达到数据库限制或发生写入错误会暂停监测并显示错误，不改变充电限制。历史文件不会自动上传。
